    iOS Simulator & macOS system proxy
    
      
    Available on macOS only (the iOS Simulator uses the Mac's network settings).
    
      
    
        
    The iOS Simulator has no proxy setting of its own – it uses the Mac's. MobileProxy sets an automatic proxy
          configuration (PAC) on all network services of the Mac. The PAC sends only the hosts below through MobileProxy;
          the rest of the Mac stays direct. The original settings are restored when MobileProxy stops; if it crashes, the PAC URL
          is unreachable and macOS falls back to direct connections (or run ./run.sh --restore-system-proxy).
